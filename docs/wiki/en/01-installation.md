# Installation

## Requirements

- Project Zomboid **Build 42.21** or later (`versionMin=42.21`).
- [TooltipLib](https://steamcommunity.com/sharedfiles/filedetails/?id=3694097672) (mod ID `TooltipLib`): required, it draws the lines in the tooltip.

## Steps

1. Subscribe to [Food Expiry](https://steamcommunity.com/sharedfiles/filedetails/?id=3815719265) and to TooltipLib on the Steam Workshop.
2. In **Mods**, enable **Food Expiry** (`batman_ErisFoodExpiry`) and **TooltipLib**.
3. Do **not** enable an original `eris_food_expiry` mod at the same time: they are declared incompatible.

The mod can be added to or removed from an existing save: it saves nothing.

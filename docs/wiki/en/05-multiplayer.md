# Multiplayer

- **Display only**: the mod runs on each client, sends nothing to the server and saves nothing.
- **Server**: add `batman_ErisFoodExpiry` and `TooltipLib` to the server mods (with their Workshop items) so that clients download them. There is nothing to configure.
- **Option**: each player sets [Exact times need Nutritionist](04-options.md) for themselves.
- **Existing world**: safe to add or remove.

The client computes the age of the food it displays itself and receives the sandbox options from the server, so the times follow the server settings.

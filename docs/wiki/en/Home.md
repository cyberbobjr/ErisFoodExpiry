# Food Expiry

**Food Expiry** (mod ID `batman_ErisFoodExpiry`) is a Project Zomboid Build 42.21 mod that shows how fresh a food item is and exactly how long before it goes stale and rots: in the item tooltip, and as a thin strip under each food in an expanded inventory stack.

It is an unofficial fork of [[B42] eris food expiry](https://steamcommunity.com/sharedfiles/filedetails/?id=3392259028) and [[B42.13] eris food expiry](https://steamcommunity.com/sharedfiles/filedetails/?id=3629527156), with the code rewritten for 42.21. The idea and the name come from eris's mod.

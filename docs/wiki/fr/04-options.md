# Options

Le mod a une seule option, réglée par chaque joueur dans **Options > Mods > Eris Food Expiry (fork batman)**. Il n'ajoute aucune option sandbox.

## Durées exactes avec Nutritionniste

Désactivée par défaut.

- **Désactivée** : tout le monde voit les durées exactes.
- **Activée** : les durées exactes s'affichent si le personnage a le trait Nutritionniste (trait ou métier), ou si l'aliment est emballé et que son étiquette est lisible, comme les valeurs nutritionnelles vanilla : personnage non illettré, assez de lumière pour lire, étiquette présente. Sinon, l'infobulle affiche un état approximatif (voir [Lire les étiquettes](02-lire-les-etiquettes.md#état-approximatif)).

> Capture à faire : Options > Mods avec la case « Durées exactes avec Nutritionniste ».

## Options sandbox vanilla qui changent les durées

| Option sandbox (nom anglais) | Effet |
| --- | --- |
| Food Spoilage | Vitesse générale de dégradation. |
| Refrigeration Effectiveness | Ralentissement dans un réfrigérateur ou congélateur alimenté (jusqu'à aucune dégradation). |
| Electricity Shutoff | Dernier jour du réseau électrique pour les réfrigérateurs et congélateurs. |
| Rotten Food Removal | Affiche **Disparaît dans** sur un aliment pourri quand elle est active. |
